Every term a university registrar has to put each exam in a time slot so that no student has two at the same
time, using as few slots as possible. Draw each course as a dot and join two dots when some student takes both.
A slot is a colour, and a clash is a line with the same colour at both ends. The timetable problem is graph
colouring.

## Colour the clash graph

The courses below are made up, but the shape is real. Survey authors call the classic exam problem one that
"extends just slightly the underlying graph coloring problem, with exams as nodes and periods as colors"
([Ceschia, Di Gaspero and Schaerf, 2022](https://arxiv.org/pdf/2201.07525)).

The fewest slots that work is the graph's chromatic number:

$$
\chi(G) = \min \{\, k : \text{the courses fit in } k \text{ slots with no clash} \,\}
$$

Computing it is NP-hard. It was on Karp's 1972 list of [NP-complete](/articles/how-hard-is-hard/np-complete)
problems, and even "do 3 slots suffice?" is NP-complete (Garey, Johnson and Stockmeyer, 1976). Checking a
finished timetable is easy; finding the best one may mean a search that grows exponentially with the number of courses, as for
[the travelling salesman](/articles/how-hard-is-hard/tsp).

## When the order is wrong

Greedy colouring never needs more than one slot beyond the most clashes any course has, but it can be far
from the best:

<div class="fx-figure">
  <Crown client:visible />
</div>

So registrars use heuristics. Welsh and Powell (1967), in a paper about timetabling, coloured the most-clashing
courses first; Brélaz's DSatur (1979) re-picks the most constrained course at each step. Modern systems add
local search on top. The standard test set, collected by Carter, Laporte and Lee (1996), holds 13 real
problems; one of them, CAR91, has 682 exams and 16,925 students
([benchmark table](https://www.cs.nott.ac.uk/~pszrq/data.htm)). The same colouring assigns CPU registers
to variables in compilers and radio frequencies to transmitters.

<Lesson>

A timetable is a coloured graph. Checking one is easy, finding the fewest slots is NP-hard, so schools settle
for good orders and local fixes.

</Lesson>
